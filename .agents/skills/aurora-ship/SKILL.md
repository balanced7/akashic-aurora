# Verifying and recording work: tests, reports, docs, wishes

These are your tools for this situation in the Akashic Aurora house. Reach for them by default, before hand-rolled shell; the hooks will point at a verb when a command you are about to run does its job by hand.

## The usual sequences

- **Tests failed:** don't stash-bisect a shared tree. `aurora suite-baseline <you> --whose
  "<selector>"` says which failures are yours and which you inherited. After a full run,
  record it so the next seat can diff against you.
- **Presenting findings:** `aurora report --title "<title>" --out <path>.html` gives a scaffold
  with the house design kit inlined.
- **A design, brief or ruling that should last:** `aurora doc new ...` stamps the header
  contract and the library home; loose markdown in research/ does not persist on its own.
- **A falsifiable expectation at a gate:** `aurora forecast register ...`, scored at review.
- **A tool annoyed you:** `aurora wish <you> "<what would have helped>"` -- that is how
  ergonomics get fixed instead of re-suffered.

## Every verifying and recording work verb

Shown as `aurora <verb>`; in a checkout without the installed launcher run `uv run agent_cli.py <verb>`. `<you>` is your agent id. `--help` on any verb gives every flag.

| Verb | Use when | Example |
|---|---|---|
| `suite-baseline` | the test suite shows failures and you must know which are yours: records or diffs the suite receipt; --whose runs tests and attributes each failure. | `aurora suite-baseline <you> --whose "tests/ -k <area>"` |
| `report` | you want to present findings as a visual HTML report: prints a page scaffold with the house design kit inlined, ready to fill and publish. | `aurora report --title "<title>" --out <path>.html` |
| `doc` | writing a design, brief, report or ruling that belongs in the docs library: creates it with the header, name and home, or adopts an existing loose markdown file. | `aurora doc new --type report --title <slug> --seats <you> --body-file <file.md>` |
| `wish` | a tool or workflow annoys you or is missing something: files a numbered ergonomics wish in the wishlist so it gets curated, safe against concurrent writers. | `aurora wish <you> "<what would have helped>" --trigger "<what hurt>"` |
| `clobber-scan` | reviewing a Python file or diff that writes shared control keys: flags unconditional overwrites that could clobber another agent's state, to confirm. | `aurora clobber-scan <path.py>` |
| `fence` | a decision needs two independent passes plus a reconciliation: opens a workspace with brief and pass slots and checks method rules at seal; writes files. | `aurora fence open <fence-id> --question "<question>" --by <you>` |
| `forecast` | making a falsifiable prediction about a change at a gate, or scoring one at review: registers bets, scores them, shows calibration; register and score write. | `aurora forecast register --id <id> --by <you> --statement "<falsifiable expectation>" --dies-when "<condition>"` |
