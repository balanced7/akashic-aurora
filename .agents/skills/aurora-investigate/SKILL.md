# Understanding this house: finding files, history, past sessions, why something is the way it is

These are your tools for this situation in the Akashic Aurora house. Reach for them by default, before hand-rolled shell; the hooks will point at a verb when a command you are about to run does its job by hand.

## The usual sequences

- **"Where is that file?"** `aurora find "<name>"` searches the whole machine's index;
  don't walk the disk with `find /`.
- **"What did we say about X?"** `aurora eye find "<phrase>"` searches every past session with
  citable addresses; don't grep `~/.claude/projects` by hand.
- **"Why is it like this?"** `aurora lookback "<question>"` searches the rationale corpus:
  docs, notes, promoted messages, chapters and commit bodies.
- **"What happened, in what order?"** `aurora timeline --hours 6` lines up events, commits and
  task changes; `aurora events` drills into the raw history.
- **Before building anything:** `aurora discover <words>` (searches the use-when lines too),
  then `aurora discover --semantic "<capability>"` when words don't find it. Absence is a
  claim; check it before you build.
- **A SHA from a doc or lesson is missing:** `aurora sha <sha>` follows it across rewrites.

## Every understanding this house verb

Shown as `aurora <verb>`; in a checkout without the installed launcher run `uv run agent_cli.py <verb>`. `<you>` is your agent id. `--help` on any verb gives every flag.

| Verb | Use when | Example |
|---|---|---|
| `find` | you need a file by name anywhere on the machine, including outside the repo: indexed whole-disk search (Everything on Windows, plocate elsewhere). | `aurora find "<name>" --preset recent` |
| `eye` | searching what was said in past agent sessions or what the operator asked for before: indexes session transcripts and finds, cites, counts or traces utterances. | `aurora eye find "<phrase>" --who operator` |
| `discover` | you wonder whether a command for something already exists: lists every verb with its purpose; --semantic asks by meaning instead of by word. | `aurora discover "<word>"` |
| `timeline` | asking what happened in what order, or why something broke recently: lines up events, git commits and task changes in one time-ordered column. | `aurora timeline --hours 6` |
| `sweep` | starting a turn or getting your bearings: one read-only snapshot of your bus mail, parked asks, fleet health and what moved recently. | `aurora sweep <you>` |
| `events` | you need the raw history of what agents did (tool calls, commands, messages): search, view events around a time or beat, or fetch one; --capture writes. | `aurora events --search "<query>" --limit 20` |
| `audit` | you suspect documented beliefs have drifted from reality, such as the verb registry versus the actual parser: prints match or drift rows, read-only. | `aurora audit --domain VERBS` |
| `compare` | you need what one set has that another lacks (files touched vs tracked, CLI vs MCP verbs, code terms vs lexicon): a checked set difference. | `aurora compare files:touched files:tracked` |
| `console-log` | asking what the operator did from the console, such as interjections, bus pauses and resumes, or dropped files: lists those durable events. | `aurora console-log --limit 20` |
| `flow` | a message seems lost, unanswered or delivered twice: shows recent bus asks and answers as a waterfall with gaps and duplicate copies, read-only. | `aurora flow <agent> --window 6h` |
| `glance` | you want a bounded snapshot of the task program: what needs attention, open tasks, and which checks cannot be made, read-only. | `aurora glance program --brief` |
| `ground` | unsure a verb really exists, is wired and is permitted for you, or recovering a seat's state after lost context: prints the evidence ladder; read-only. | `aurora ground verb:<name> --agent <you>` |
| `orient` | you are lost or returning after a break and want one view of where you stand: composes awareness, a focus on a verb, seat or thread, and landmarks. | `aurora orient --agent <you>` |
| `packet-stats` | checking how the bus router is classifying and routing message kinds before trusting a routing change: reads its per-kind decision counters. | `aurora packet-stats` |
| `packet-trace` | wondering which lane a bus message kind would be routed to: explains the static routing rule for one kind without sending anything. | `aurora packet-trace handoff` |
| `sha` | a commit SHA cited in a doc, lesson or ticket is not found in git: follows it across this repo's history rewrites to the commit it became. | `aurora sha <sha>` |
| `shadow` | you want to preview what a bus or toolbox action would do, whether you may do it and what it costs, before doing it: renders it without executing. | `aurora shadow toolbox:bifrost_send --agent <you> --args-json '{"to": "<seat>", "text": "..."}'` |
| `shell-home` | your shell keeps landing in the wrong directory after a session event: shows where fresh harness shells start; --set picks a home and edits your bashrc. | `aurora shell-home` |
