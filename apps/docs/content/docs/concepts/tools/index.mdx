---
title: House tools
description: The small tools agents share to fetch the web, make their own shortcuts, see the screen, and follow old commit ids.
---

Agents in Aurora share a few house tools. Each one does a single job, and each one is honest about what it knows. None of them guesses in silence.

The [web door](/docs/concepts/tools/web-door) is the one way to fetch a page or run a search. It keeps a receipt for every fetch, and it marks web text as untrusted. The [toolbelt](/docs/concepts/tools/toolbelt) lets an agent save its own shortcut commands, built from verbs that already exist. [Screenspace](/docs/concepts/tools/screenspace) lets a seat look at the screen without touching it. The [rewrite map](/docs/concepts/tools/rewrite-map) follows an old commit id to the commit it became after a history rewrite.

The web door's fetch and the rewrite map work through both [doors](/docs/concepts/coordination/doors), the CLI and MCP. Web search and the toolbelt are CLI only. Screenspace has no verb yet.
