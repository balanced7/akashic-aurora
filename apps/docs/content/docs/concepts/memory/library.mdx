The library gives every house document a home. Each document is an atom, a versioned record that only grows. The markdown file you read is a projection, a copy that a program prints from the atom. Think of a master copy kept in a vault. A program prints the shelf copies from it. When a shelf copy and the master disagree, the master wins.

## Why it exists

The goal was simple: know where to find anything, at once. Docs had sprawled across the repo. Worse, some still gave orders that no longer applied. One doc called itself the "SINGLE SOURCE OF TRUTH" for a model the project had dropped. A fresh agent reading it would have followed dead rules. The fix minted the docs as atoms first. Then one commit deleted the 621 tracked originals. It pointed every reference at the new projections. Every byte survived.

## How it works

- **Atoms are the truth.** Each atom follows the [append-only record](/docs/concepts/foundations/append-only-record) pattern. It lives in the [store](/docs/concepts/foundations/store) for fast reads. Git also tracks a file per type, `store/docs/<type>.jsonl`. It gets one line per version event: a new version or a status change. If the store loses its copy, a rebuild replays the file.
- **Markdown is a projection.** Each file under `docs/library/` carries a "do not edit" banner and the atom's id.
- **A path says only the type.** There are eight types: contract, map, design, brief, report, chronicle, ledger and ruling. Arc, author and status live in the header. To change a category, you print a new catalog. You never move the file.
- **Living docs and dated docs.** A living doc is one an agent can act on today. Its header says `Status: current`; that is the marker. Contracts usually carry names in capitals, such as `LIBRARY.md`. The generated maps in `docs/` are living too. A dated doc carries its date in the name, or lives as an atom.
- **Every doc states its status.** A top-level doc in `docs/` must say `current`, `superseded-by` or `historical` near the top. A checker fails a doc with no status. It warns about a `current` doc untouched for 45 days. Atoms use their own set: `current`, `draft`, `superseded` and `fossil`.

One mismatch to know: `LIBRARY.md` lists `current`, `superseded by` and `fossil` for the header, but the checker accepts `current`, `superseded-by` and `historical`.

## How you use it

```bash
aurora doc new --type design --title my-plan --draft
aurora doc adopt research/in-flight/my-findings.md
```

`doc adopt` mints an atom from a loose file you already have, and leaves that file untouched. Use it for drafts outside `docs/`. A commit guard refuses a new loose `.md` under `docs/`, so start there with `doc new`.

Read `docs/INDEX.md` for the living set. `docs/SHELVES.md` counts the docs by type. A script, `scripts/generators/gen_library.py`, writes it, and its counts can lag. Run that script before you trust them.

### The codex

<Callout type="warn" title="Planned, partly built">The codex has its first parts in code, but its pages are not built, and the project has set the design aside.</Callout>

The codex was a plan for knowledge that tidies itself. Its pages would never be hand-edited. A program would group related atoms and write a summary for each group. To merge two pages, it would regroup and rewrite. The plan aimed to stop a common rot: hundreds of weak pages no one dares to merge. A page schema and a version history exist, but only tests call them. A grouping step and an embedder exist too. The story theme finder borrows the [embedder](/docs/concepts/memory/ranker-and-distiller) only. The grouping step has no live caller. There is no `codex` command.

## Don't confuse it with

- **"The codex" in `docs/ARCHITECTURE.md`** — a nickname for the whole knowledge and memory block. It means this section, not the plan above.
- **Codex the agent** — an outside coding agent that holds the `sol` seat. See [Seats](/docs/concepts/bifrost/seats).
- **[Chronicles](/docs/concepts/memory/chronicles)** — digests made from notes and story beats, not house docs.
- **[Manuals shelf](/docs/concepts/tools/manuals-shelf)** — outside vendor manuals, not house docs.
