Akashic Aurora is a shared memory for AI agents. Agents **boot** to load past lessons, **learn** to record new ones, and **recall** to search them. All you need is [uv](https://docs.astral.sh/uv/), which handles your Python environment.

## Set up with agents

Paste the prompt into any agent that can run commands, or start one straight from your terminal (bash or PowerShell). It asks before running anything.

```text tab="Prompt" tab-group="agent"
Set up Akashic Aurora for me, a shared memory for AI agents.

- Clone https://github.com/balanced7/akashic-aurora.git and cd into it.
- If uv is not installed, install it (https://docs.astral.sh/uv/).
- Add a permanent `aurora` command to my shell profile, unless one
  exists, that runs:
  uv run -p 3.12 --project <clone> <clone>/agent_cli.py
  (with <clone> as the absolute path to the clone)
- In a fresh shell that loads my profile, run these and show me the output:
  aurora boot me --task first-run
  aurora learn me --experiment first_try --tried cloning --result booted
  aurora recall first_try
- Read AGENTS.md and tell me, in a few sentences, how you will use
  Aurora while we work together.
```

## Set up on your own

**1. Install uv** (skip if you have it), then open a new terminal:

```bash tab="macOS / Linux" tab-group="os"
curl -LsSf https://astral.sh/uv/install.sh | sh
```

```powershell tab="Windows" tab-group="os"
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**2. Clone and run:**

```bash tab="macOS / Linux" tab-group="os"
git clone https://github.com/balanced7/akashic-aurora.git && cd akashic-aurora
alias aurora='uv run -p 3.12 agent_cli.py'

aurora boot me --task first-run
aurora learn me --experiment first_try --tried cloning --result booted
aurora recall first_try
```

```powershell tab="Windows" tab-group="os"
git clone https://github.com/balanced7/akashic-aurora.git
cd akashic-aurora
function aurora { uv run -p 3.12 agent_cli.py @args }

aurora boot me --task first-run
aurora learn me --experiment first_try --tried cloning --result booted
aurora recall first_try
```

The alias lasts for this terminal session and works from inside the repo.

Next: read [`AGENTS.md`](https://github.com/balanced7/akashic-aurora/blob/master/AGENTS.md) in the repo.
