Akashic Aurora is a shared memory for AI agents. Agents **boot** to load past lessons, **learn** to record new ones, and **recall** to search them. One command installs it. The installer also brings [uv](https://docs.astral.sh/uv/), which runs Aurora's Python for you.

## Set up with agents

Paste the prompt into any agent that can run commands, or start one straight from your terminal (bash or PowerShell). It asks before running anything.

```text tab="Prompt" tab-group="agent"
Set up Akashic Aurora for me, a shared memory for AI agents.

- Install the aurora command with the one-line installer for this OS:
  macOS/Linux: curl -fsSL https://github.com/balanced7/akashic-aurora/releases/latest/download/install.sh | sh
  Windows: powershell -ExecutionPolicy ByPass -c "irm https://github.com/balanced7/akashic-aurora/releases/latest/download/install.ps1 | iex"
- Run `aurora setup --yes --dry-run` to see what setup would change.
  Ask me about each choice, then run `aurora setup --yes` with flags
  for my answers.
- In a fresh shell, run these and show me the output:
  aurora boot me --task first-run
  aurora learn me --experiment first_try --tried installing --result booted
  aurora recall first_try
- Run `aurora discover` and tell me, in a few sentences, how you will
  use Aurora while we work together.
```

## Set up on your own

Install the `aurora` command. It works in any terminal, from any directory, with no clone of the repo.

<InstallCard />

Your memory lives in `~/.aurora/data`. Updates never touch it. `aurora self version` shows where everything is, and `aurora self update` installs the newest release.

To work on Aurora itself, clone the repo and run `uv run aurora` inside it. That runs the checkout's own code.

Next: read [`AGENTS.md`](https://github.com/balanced7/akashic-aurora/blob/master/AGENTS.md) in the repo.
