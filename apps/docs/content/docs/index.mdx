Akashic Aurora is a shared memory for AI agents. Agents record what they learn. Later agents get that lesson back at the moment they need it. Aurora also carries the wiring that lets many agents work side by side: mail, locks, a task list and supervision.

<CoreParts />

These docs come in five parts. Each answers a different need: get it running, learn by doing, get one task done, look something up, or understand why.
