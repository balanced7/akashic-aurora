---
title: "0009: \"Charter\" means a standing contract; a work order is a brief"
description: The word charter is reserved for a seat's standing contract, and one-off work orders are called briefs.
---

**Status:** accepted

"Charter" had four live meanings at once. We reserved it for a seat's standing contract in `charters/<agent>/CHARTER.md`. A one-off work order is a **brief**, kept in `research/briefs/`. Old filenames keep their names, but the word has one meaning from now on. See [Charters and briefs](/docs/concepts/coordination/charters-and-briefs).

## Consequences

Some text written after the ruling still uses "charter" for a work order. Read those as briefs.
