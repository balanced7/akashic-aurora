---
title: "0007: Union, not consensus"
description: When several models review the same work, we keep every distinct finding and verify each one, instead of keeping only what they agree on.
---

**Status:** accepted

Multi-model reviews merge by union, then check each finding. We never gate on agreement. We chose this because a finding here often costs one command to check. Merging only what models agree on throws away the rare true finding. In one panel, only one model family found a real argument-length bug.

See [Union, not consensus](/docs/concepts/method/union-not-consensus).
