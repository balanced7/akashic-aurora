THE 5 PATTERNS (Memorize These)
================================================================================

Pattern 1: load_X_from_Y()
  Meaning: Retrieve existing X from source Y
  Example: load_cached_decision_by_name()

Pattern 2: cache_X_for_Y() / store_X_in_Y()
  Meaning: Store X for purpose Y
  Example: cache_decision_for_reuse()

Pattern 3: record_X_preventing_Y()
  Meaning: Track X because it prevents Y
  Example: record_blocker_preventing_progress()

Pattern 4: emit_X_causing_Y()
  Meaning: Signal X that causes side effect Y
  Example: emit_signal_causing_state_change()

Pattern 5: derive_X_from_Y()
  Meaning: Compute X from source Y
  Example: derive_agent_context_from_startup_sources()

ALL DOCSTRINGS INCLUDE: "Semantic Relationship: X causes_Y" etc.
