What the audit did to our prior claims

CONFIRMEDas_of rides every read endpoint — even document content and provenance. The whole temporal law is one sentence: known_at belongs to an evidence row, as_of belongs to a request; a row is eligible only when known_at ≤ as_of. The facet surface is real, exact-phrase-last, and richer than we knew: operator syntax (source: entity: type: rel: -term) plus an "interpreted as" echo showing how the query was parsed.
CORRECTED"No semantic search at all" — already cited in two design docs — is wrong at the API level. A vector lane exists (match=, halfvec cosine) but only in the document plane, only as a second-stage reranker after the role/facet filter, never on /search, and Pro-gated. The lesson's rule — embeddings enhance a facet surface, never substitute for one — comes out strengthened, with sharper edges.
THEIR DEFECT/compare with period=2025-03 returns silent empty; 2025-03-01 returns the full revision record. A mis-shaped selector that matches nothing instead of teaching — the one errors-that-teach failure we found, and a pin for anything we build.
NOT VERIFIEDVector-rerank behavior and batch search are Pro-gated (403 with a clean upgrade message); sealed provenance packs are Institutional-gated. Documented, not behaviorally verified on the Free tier — and said so here in the same voice as the passes.

The one genuine design disagreement

PRIORISH: OPEN VOCABULARY Let the extractor mint relation types freely; ship a discovery endpoint. 4,277 types capture nuance no committee would specify (INFLUENCES_ACQUISITION_STRATEGY). Cost, measured tonight: a fragmented graph — the Federal Reserve has four neighbors because entity variants never merge, and /relation-types exists because nobody can know the vocabulary.
AKASHIC: GOVERNED KINDS Four edge kinds with defined semantics; new kinds pass a gate. Every edge means something an agent can act on, and the lexicon stays liftable. Cost: expressiveness ceiling — nuance gets flattened into related_to or never recorded at all.
SYNTHESIS Govern the core, permit an extracted tail. Keep the four load-bearing kinds gated; let extraction propose typed candidates into a quarantine namespace behind a discovery verb, and promote by usage — the same funnel lessons already ride. Their thin-graph failure is the RED pin: canonicalize entities before minting vocabulary.

a compare verbTwo bounded reads + in-process delta. Trivial once as-of exists; with a 422 on mis-shaped selectors, per their defect.
degraded flag on recallWhen the funnel clips, say so in the response envelope. One boolean plus a reason string; silence currently reads as completeness.
MCP curation pass36 tools → a coached core, with usage instructions in the handshake. Their 7-tool door is the strongest ACI argument tonight produced.
NOT embeddingsTheir search door has none either; their vector lane is a Pro-gated reranker — and their own terms disclose it leaks post-cutoff knowledge into ranking. Our three empty sockets stay open, correctly, until the facet surface exists.
NOT hash-sealing everythingEven they seal documents only; numeric observations ride unhashed. Our sha-addressed doc atoms already match the grade that matters.
NOT an NL/SSE query doorAsk-mode is a product surface for humans. The fleet speaks structured queries natively; build the dimensions first.
