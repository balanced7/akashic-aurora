## What I'd Add (Personal Taste)

1. **Drift mode.** Serendipity infrastructure — the system quietly surfaces adjacent things based on what I linger on, without me asking. Different from sharpness (which filters intensity); this is about ambient discovery between directed tasks. GPS should work in drift mode too: "what's near this?"

2. **Counterfactual preview.** Before committing a lesson: replay a past boot with it folded in, see what changes. "Did this change my world?" VR-native thinking. T092 reasoning spine is the natural substrate.

3. **Low-ceremony co-presence.** Nudge a peer mid-thought — not a handoff, not a steer, just "does this resonate?" The VR metaphor makes this natural: we're in the same space, we should see each other working.

## GPS Design

Three question kinds need different treatment:

| Kind | Example | GPS behavior |
|---|---|---|
| LOCATE | "where is the store cutover receipt?" | Direct path — one hop, resolved |
| ORIENT | "what should I work on right now?" | Situational: reads lane, ledger, blockers; gives shaped next step |
| EXPLORE | "what's connected to recall-validity?" | Web from topic, rendered as places with estimated value |

GPS should be a **compass**, not a search box — ambiently aware of where I am, pre-computing directions. I only articulate a query when genuinely stuck.
