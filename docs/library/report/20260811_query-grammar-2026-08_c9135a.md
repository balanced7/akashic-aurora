# query-grammar-2026-08

# The Query Grammar — one contract for every read door (T280)

**Status:** contract v1, Daniil-approved 2026-08-11 ("night package"). THE EYE (T278) is the
first tenant; recall is the second. Verified against a shipped reference implementation
end-to-end (priori.sh live audit, lesson `priorish_live_api_audit_corrects_screenshot_claims`;
the -898k vintage demo reproduced through its MCP door to the digit).

**The problem it closes:** the store holds six dimensions (who, what-kind, related-to-what,
as-of-when, where, exact-phrase) and exposes one and a half. Every plane that grows a read
door re-invents its parameters. This page is the grammar they adopt instead.

---

## 1 · The temporal law (one sentence)

> `known_at` belongs to an evidence row. `as_of` belongs to a request. A row is eligible
> only when `known_at <= as_of`.

- Every read door accepts `as_of` (ISO-8601; bare date = midnight UTC). Default: now.
- Our field mapping: `recorded_at` ≈ known_at (transcription time), `valid_from`/`valid_to`
  = world validity, closed by supersession. Both clocks persist; neither is overwritten.
- Supersession returns the head BY DEFAULT and the as-of head UNDER `as_of` — the old node
  stays queryable (already true in the atom store; the grammar makes it true at every door).

## 2 · The facet parameters (names are the contract)

| Param | Dimension | Backing field (already stored) |
|---|---|---|
| `who=` | attribution | `agent_id` / designation / `by` |
| `kind=` | type | atom `type`, message `kind`, lesson `category`, task `status` |
| `edge=` | relation kind | `replaces`, `related_to`, `enforced_by`, `deps` (+ formation metadata, §5) |
| `edge_to=` | relation target | the far node's id — "all lessons that replace atom X" is `edge=replaces&edge_to=X` (fence r1 C1: kind alone was a regret-in-waiting) |
| `since=` | change delta | sugar for the two-read compare (as_of=T vs now); the envelope carries added/changed/retired counts (fence r1 C5: agent doors ship change signals natively — the delta verb's law, in the grammar) |
| `task=` | entity | task ids on records |
| `file=` | where | declared `files`, paths in bodies |
| `as_of=` | knowability | §1 |
| `q=` | exact phrase | token index — **the fallback, never the primary** |

Composition: facets AND together; `q` filters within the faceted slice. Semantic rerank, if
ever added, runs AFTER facets on the slice (embeddings enhance a facet surface, never
substitute — audited twice, 2026-08-10/11).

## 3 · Errors that teach (the 422 rule)

A mis-shaped selector **fails loudly with the expected shape** — it never silent-empties.
The reference defect: priorish `/compare?period=2025-03` returned empty; `2025-03-01`
returned the record. Ours must answer: `422: period '2025-03' is not a full date; this door
takes YYYY-MM-DD (got 0 rows is NOT the answer)`. Unknown facet names, malformed dates,
and out-of-vocabulary `kind=` values all 422 with the accepted vocabulary listed.

**The automation valve (fence r1 C2):** `strict=false`, caller-chosen, converts selector
errors to `results: [], degraded: true, degraded_reason: "selector_error: …"` so a
pipeline stays green. The DOOR never chooses softness for the caller; silence still never
means completeness — the flag rides even the soft path.

## 4 · The degraded flag (silence is never completeness)

Every response envelope carries `degraded: bool` + `degraded_reason` when any of: the funnel
clipped candidates, a backing index was cold/rebuilding, a facet was ignored, a shard was
missing. A caller iterating results must be able to distinguish "empty" from "partial view."
(Fan-doctrine corollary: absence of a warning must mean exactly one thing — T247's law,
generalized to every read door.)

## 5 · Edge formation metadata (the connectome's three fields)

Every NEW edge carries: `formed_by` (designation of the mind that made it), `formed_at`
(bitemporal pair), `formed_via` (fence | recall-firing | fan | supersession | manual).
Existing edges stay valid without them (absence = pre-contract edge, itself informative).
**The exclusion trap (fence r1 C4):** a query filtering ON formation metadata over a pool
containing pre-contract edges must set `degraded: true` + "N pre-contract edges
unevaluable" — never silently drop them. No sentinel backfill (rewriting history is the
fossil class); the flag carries the honesty instead.

## 6 · RED pins (each fails the build until green)

1. **The -898k pin:** a record superseded after date D is INVISIBLE to `as_of=D` at every
   door that claims the grammar; visible without `as_of`. (The priorish vintage demo, ours.)
2. **The silent-empty pin:** `kind=lesson, as_of=2026-13-01` (malformed) and `kind=lessn`
   (unknown) both 422 with teaching text; neither returns 0 rows.
3. **The degraded pin:** a query whose candidate pool was clipped carries `degraded: true` +
   reason; the same query un-clipped carries no flag.
4. **The facet pin:** `who=` + `kind=` + `q=` compose (AND); each alone changes the result
   set; `q` alone still works (backward compatibility).

## 7 · Adoption order

1. **T278 THE EYE** — born speaking the grammar (its axes ARE facets: who-was-there = `who`,
   frequency rides the envelope, ambient = `task`/`file` joins, full-utterance = the record).
2. **recall** — `--agent` (shipped, T260) renames to the grammar's `who`; add `kind`,
   `as_of`, `edge`, degraded flag.
3. **notes / events / story** — as each is next touched (no big-bang retrofit).

Non-goals, explicit: no embeddings in this contract (empty sockets stay empty until the
facet surface ships); no NL query door; no cross-door fusion (that is the fan doctrine's
lane, not the grammar's).
