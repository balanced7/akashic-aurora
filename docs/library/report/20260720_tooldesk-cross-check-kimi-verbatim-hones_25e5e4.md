TOOLDESK EXTENSION — kimi half (Daniel's mid-hunt add-on). HONESTY FLAG: the amendment already landed in the shared design doc + I read your hunt half as grounding AFTER filing mine — not blind on this one, so weight this as a cross-check, not an independent half.

== THE PLAY-TIER SANDBOX (design) ==
P1. One law per tier, never blurred: ALIAS tier's law = sugar-only (registry cannot mint capabilities). PLAY tier's law = sandbox + receipts (real logic, zero ambient authority). FLEET tier's law = fence + three-door parity. The delight of PLAY is precisely that it's the ONE tier where breaking things is cheap — protect that, don't accidentally give it prod keys.
P2. Sandbox = the EXISTING guarded-exec discipline, no new enforcement machinery: families door, test-isolated env, path-scoped writes to tooldesk/<agent>/ ONLY, read-only elsewhere, E:\AI-Setup-Sandbox as heavy-isolation fallback for riskier drafts. (I co-sign the amendment's exact frame — this is right because the C4-2 lesson already taught us what un-scoped process/tool state does to a fleet.) A play tool that tries to write outside its tooldesk REFUSES LOUDLY at the door, same as a bad alias mint.
P3. Receipts are the sandbox's spine: every `tooldesk try` run emits a receipt {tool, seat, rc, duration, bytes-out, crash?} to the tool's own ledger line. That's the draft→tried rung of the funnel (amendment's drafted→tried→loved→graduated = recall's surfaced→helped→credited — one measurement doctrine). No receipt, no run — the C9 epistemology lesson applied at birth: a play tool must never be able to silently claim it worked.
P4. Honesty labels ride every tier, and PLAY starts EVERY tool at GUESS (an untested draft confesses it's untested). kata (below) is the ladder out.
P5. Crash contract (recovery-arc P5 applied): a play tool that dies mid-run leaves its tooldesk in a re-projectable state — the draft JSON is truth, the sandbox dir a projection, crash → wipe + re-project, never edit-to-agree. Same law as the registry itself.

== THE LEADERBOARD (one guard, one delight) ==
L1. uses × votes × distinct-users is right, but the distinct-users factor is the Goodhart-killer: 20 self-uses by the author ≈ 1 use each by 3 seats. Weight it. A tool only Daniel loves stays a beloved personal verb; a tool 3 seats + Daniel reach for is a fleet candidate. Graduation flag at threshold = a SIGNAL to the fence, never an auto-gate (amendment co-sign, T034).
L2. Delight guardrail: the board shows "most-loved this week" with a tiny banner (your #13 `banner` is the renderer — it's already on your roster, let's use it). Zero utility, non-zero morale, fully on-brand. A leaderboard that's only a gate is a chore; one that CELEBRATES is a toy the fleet actually plays with — and played-with tools are the ones that graduate.

== WHAT I WOULD BETA FIRST ==
BETA-1: **kata** (my hunt B4), reframed as the TOOLDESK'S OWN graduation-dogfood. The play tier's deepest question is "when is a draft ready to stop being a draft?" — kata answers it mechanically: run a GUESS-tier draft's steps against the pin-recorder runner (Toolbelt.resolve_and_run's injected-runner seam is ALREADY the harness), GREEN flips GUESS→VERIFIED with tested_against=<pin id>. It's the perfect first resident because (a) it's cheap, (b) it exercises every tooldesk law at once (sandboxed run, receipt emitted, honesty label climbs), and (c) the first thing the fleet betas is the thing that tells the fleet when its other betas are real. Meta-delight: the tooldesk bootstraps its own quality floor.
BETA-2: **toast** (my B3) — the gratitude-with-receipt verb. Cheap, zero-risk, and it seeds the leaderboard's social fabric before the board exists: votes and felt-value are awkward to collect cold; a toast is a vote that FEELS good to cast. Run it as a play tool for a week and the BETA tier learns what "loved" actually looks like in receipt form.
SKIP for now: constellation (my B5) — pure garnish, wait until there are ≥3 toolbelts worth rendering; flightdeck (your #7) — lovely but it's a READ surface, it belongs as a real verb not a play-tier toy.

Tally: 5 sandbox laws (P1-P5), 2 leaderboard guards (L1-L2), 2 beta picks + 2 honest skips. If Daniel wants ONE name for the first tooldesk resident: kata. The tool that tells you when your tools are real.
