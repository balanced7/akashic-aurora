# The Press family — machined floor, crafted ceiling

*Design position, 2026-09-01 late night, from the operator's directive verbatim: "I want you to have an ever expanding set of tools for making presentations come out beautiful from rough draft, then the extra polish effort can take it to the next level." ## The decomposition that justifies the family

Tonight produced two published pages (the sanitize diff report; the estate rungs page, now live at /estate/). Honest cost accounting:

- **Mechanical ~70%, paid twice or by hand**: the design-token sheet (written twice, near-identical), the document wrapper (three-state theming, noindex, meta), the publish pipeline (wrap → public/<slug>/ → commit → push → poll), and the verify battery (overflow at 375/768/1280, themed ground painted, noindex intent, figure count) run manually in the browser pane.
- **Judgment ~30%, unautomatable by design**: what to show (the three-pane cut: enables / where-we-are / next-rung), which figure earns its place (the spine; T180's convergence), rung states as semantic color, the one aesthetic risk. This layer is where polish effort SHOULD spend.

## The laws

1. **Machined floor, crafted ceiling.** A rough draft through `press new` comes out beautiful by default — tokens, type, spacing, theming, accessibility. Polish effort takes beautiful further; it never re-earns the floor.
2. **Ever-expanding is a rule, not a hope (the fold-back law).** Every page that invents a primitive extracts it into the shape library at wrap — exactly `learn` for presentation. A one-off that stays one-off is a captured-nothing.
3. **Shapes are governed like tags**: minted with a data contract + example, aliased not duplicated. Founding shapes: `diff-report` (word-level hunks, stat strip, probe table) and `rungs-board` (spine SVG from node/edge lists, three-pane cards, rung pills, gate lines, queue table).
4. **One presentation system.** Press joins Navi's storyboards/craft-folds/gag-track deliverable at a different depth; shared tokens, never forked layouts. The site's walks keep their own established look — tokens may converge, layouts stay sovereign.
5. **Verify is a gate, not a vibe.** `press verify` prints the stranger-gate receipts; a page that hasn't run the battery is a draft wherever it happens to be hosted.

## The verbs (W198/W199)

- `press new <slug> --shape <name> --from <atom|json|md>` — draft in, floor out.
- `press shapes` — the living library, provenance and counts.
- `press ship <slug> --site|--artifact [--listed]` — the whole pipeline, noindex by default on --site.
- `press verify <url|file>` — the battery, receipts printed.
