## 3. The plays

1. **Decision packets for every gate item.** One screen each: the ask, recommendation, strongest
   dissent authored by a DIFFERENT seat, cost/reversibility, default-if-silent, as-of stamp
   (kimi F6: undated "do this FIRST" lines burn newcomers and operators alike).
   Pilot: docs/gate-packets-2026-07-18.md (drafted today; deepseek owns the dissent column).
2. **Dual-strata review as standing method.** The walk proved resident and outsider reviewers
   catch non-overlapping defect classes. Load-bearing artifacts get BOTH: deepseek
   (execution-model class) + kimi fresh-eyes (staleness/door/noise class, ~$1/round).
3. **Kimi 1M coherence sweep as a new instrument.** Whole-repo + research + chronicles in ONE
   context: hunt the staleness genus (stale directives, retracted-but-cited designs, ghost
   claims) as a service, per-arc or weekly. Propose as a new ledger item.
4. **Vision probe pointed at real work.** Kimi's protocol-step-4 probe targets T007 (Void theme
   verify) and T033's screenshot evidence needs — capability validation doing ledger work.
5. **Heterogeneous N-version blind for wide-solution-space design** (T080 operator traffic,
   T038 work-token negotiation): blind halves across DIFFERENT models (claude/deepseek/kimi/
   gemini-free), then judge/reconcile. Model diversity > same-model redundancy for creative
   range. Mechanical work stays single-lane cheap (frugality).
6. **Soak window = design territory.** Until the soak receipt: deepseek authors T095 M1 opening
   (charter: claims are runner domain); T092 reasoning-spine §R closure continues; gemini
   prior-art sweep feeds T086. Build starts on receipt against an already-reconciled spec.
7. **Ledger hygiene so the roster maps to the ledger:** register seat arcs as tasks (kimi F4),
   Daniel rules T020/T032 stale proposals, kimi phase-2 graduation after vision probe +
   fresh-eyes complete the evaluation (deepseek review already says GRADUATE).
