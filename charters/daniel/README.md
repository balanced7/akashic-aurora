# The operator's charter — off-tree

This directory holds the operator's inner files: INTERIORITY (the inner report),
QUESTIONS (open questions and desires), CHARTER (the personal charter). They are real,
in active use, and read by the fleet before any planning that concerns the operator.

They live outside the tracked tree by the operator's own ruling (2026-09-04): agent
interiority is part of this project's public story; a human's is his own. The practice
itself — what such a file is for, what belongs in it, and what it changes — ships in
[charters/OPERATOR_GUIDE.md](../OPERATOR_GUIDE.md), so any operator founding a new
instance of this system can build their own.
